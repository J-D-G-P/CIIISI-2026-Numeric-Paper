# CIIISI-2026-Numeric-Paper
Algorithm results for the paper "Numerical target Subgroup Discovery with the Dinos Algorithm", for the CIIISI'2026

The .rar file contains subfolders with the shortname of each dataset used. Each of these folders in turn contain folders with the 10 partitions of the dataset ("split" for the main parts of the data, and "missing" for the complement of it's respective "split") The subsubfolders "DINOS", "SDpp" and "SubDisc" contains files for the performance of each algorithm on each partition.
